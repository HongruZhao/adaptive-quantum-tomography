## Repeat the run

From the repository root, choose a new output directory so that preserved `results/paper` files remain intact:

```sh
cd simulation
python3 -m pip install -r requirements.txt
export PYTHONPATH="$PWD/src"
python3 -B scripts/check_release.py
python3 -B -m unittest discover -s tests -v
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  python3 -B -m adaptive_tomography run --config configs/paper.json --output results/new_paper
python3 -B -m adaptive_tomography plot --results results/new_paper --output results/new_paper/figures
```

Set `MPLCONFIGDIR` to a writable cache directory and `MPLBACKEND=Agg` when needed on a headless machine. The full output arrays from this verification are retained in the local audit; their hashes and shapes are recorded here instead of committing a second large data bundle.
