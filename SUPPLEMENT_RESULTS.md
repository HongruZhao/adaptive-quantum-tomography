# Supplementary Lean coverage

This table describes the retained supporting proofs and the scope of the current supplementary statements. A row may use several proved components rather than one combined Lean declaration. The nine main result statements and their explicit hypotheses are documented separately in [MAIN_RESULTS.md](MAIN_RESULTS.md).

The three identified scope differences are resolved in the current supplement: S4.1 uses the fixed nearest-projector selection, S4.2 assumes almost-sure consistency, and S6.2 treats the actual adaptive ridge procedure and uses normalized normal-operator convergence with direct score linearization. Main theorem statements, algorithms, numbering and all Lean code/build inputs are unchanged. No conclusion is introduced as an assumption. See the [scope and reference audit](lean/verification/20261020/SUPPLEMENT_SCOPE_ALIGNMENT.md).

The [machine-readable ledger](lean/docs/SUPPLEMENT_CORRESPONDENCE.json) lists the declarations and scope. `SupplementAudit.lean` checks 138 supplementary entries, some overlapping the 498 main entries, and audits the transitive axioms of **all** retained mathematical declarations. A fresh source build and a standard-only axiom audit establish validity of the Lean statements. Source-level correspondence is separately reviewed; Lean does not mechanically parse the LaTeX statements. Seven existing endpoint types and axiom sets were checked for the present scope alignment using the unchanged compiled tree.
