# Supplementary Lean coverage

This table describes the retained supporting proofs. It does **not** assert that every printed supplementary formulation has an exactly matching endpoint. The nine main result statements and their explicit hypotheses are documented separately in [MAIN_RESULTS.md](MAIN_RESULTS.md).

Three generality differences remain: arbitrary nearest-projector selection in Lemma S4.1, convergence-in-probability-only transfer in Lemma S4.2, and the generic process/arbitrary qualifying fit of Lemma S6.2. The checked instances used for the main procedures remain included. No missing conclusion has been introduced as an assumption to disguise a gap.

| Printed result | Retained proof | Scope |
|---|---|---|
| Corollary S1.1: Pure-state loss distributions | [PureLossDistributions](lean/QubitOracle/AdaptiveDesign/PureLossDistributions.lean) | **covered main-procedure case**. The actual phase-paired corrected estimator and its loss distributions. |
| Lemma S3.1: Bounded martingale sums | [BoundedMartingaleLogRate](lean/QubitOracle/AdaptiveDesign/BoundedMartingaleLogRate.lean) | **covered**. Strong law and logarithmic rates for bounded martingale differences, extended coordinatewise. |
| Lemma S3.2: Freezing and averaging | [RidgeBatchSchedule](lean/QubitOracle/AdaptiveDesign/RidgeBatchSchedule.lean) | **mapped component proofs**. The refresh/freezing identities and convergence are explicit. Averaging also uses Mathlib Cesaro results; there is no single combined endpoint named after the printed lemma. |
| Lemma S3.3: Direct adaptive asymptotic normality | [GeneralMartingaleCovarianceCLT](lean/QubitOracle/AdaptiveDesign/GeneralMartingaleCovarianceCLT.lean) | **covered**. Bounded Euclidean martingale differences with the stated conditional covariance limit, including positive-semidefinite limits. |
| Lemma S4.1: Projection and normalization bounds | [SharpTangentGeometry](lean/QubitOracle/AdaptiveDesign/SharpTangentGeometry.lean) | **generality difference**. Tangent/retraction identities and constants are retained. The nearest-projector expansion is proved for the implemented deterministic nearestVector selection, including ties; the printed arbitrary nearest-projector selection is broader. |
| Lemma S4.2: Transfer to smooth coordinates | [PureSmoothChartEndpoints](lean/QubitOracle/AdaptiveDesign/PureSmoothChartEndpoints.lean) | **generality difference**. The transfer endpoints assume almost-sure consistency, whereas the standalone printed lemma assumes convergence in probability. Main algorithm endpoints prove almost-sure consistency. Coordinate identities and covariance transformation are retained. |
| Proposition S5.1: Reference basis construction | [ElementaryReferencePOVM](lean/QubitOracle/AdaptiveDesign/ElementaryReferencePOVM.lean) | **covered**. The concrete finite randomized-projective reference, complete law, positivity, identification and Fisher-symmetry construction. |
| Lemma S6.1: Multinomial score covariance | [MultinomialGLSIdentity](lean/QubitOracle/AdaptiveDesign/MultinomialGLSIdentity.lean) | **covered**. The finite categorical score/covariance cancellation identity. |
| Lemma S6.2: Fitted-weight cancellation | [TangentGLSLinearization](lean/QubitOracle/AdaptiveDesign/TangentGLSLinearization.lean) | **generality difference**. The implemented adaptive GeneralPOVM/Algorithm 3 case is proved. The printed generic predictable rotated-POVM process with an arbitrary qualifying preliminary fit, including the generic ambient inverse-operator limit, has no exactly matching standalone endpoint. |
| Lemma S7.1: Bounded martingale moments | [SupplementProbability](lean/QubitOracle/AdaptiveDesign/SupplementProbability.lean) | **covered**. Gaussian-type tails and all positive real moments for bounded centered Euclidean martingale differences. |
| Proposition S7.2: Mixed-qubit moment bounds | [SupplementMoments](lean/QubitOracle/AdaptiveDesign/SupplementMoments.lean) | **covered**. Inverse-Gram and actual raw/physical mixed-estimator moments of all positive real orders; fourth-moment endpoints are also retained. |
| Proposition S7.3: Pure-state moment bounds | [POVMEstimatorMoments](lean/QubitOracle/AdaptiveDesign/POVMEstimatorMoments.lean) | **mapped component proofs**. All integer moment orders for the actual estimators; RealMomentBounds provides the positive-real-order interpolation used with them. |
| Proposition S8.1: Identification, positivity and Fisher symmetry | [GlobalPFSICReferenceMinimum](lean/QubitOracle/AdaptiveDesign/GlobalPFSICReferenceMinimum.lean) | **covered**. The finite covariance-example measurement, positivity and exact minimum reference mass, with its information and identifying results. |
| Lemma S8.2: Tangent Gram and noise coefficients | [LibraryTangentFrame](lean/QubitOracle/AdaptiveDesign/LibraryTangentFrame.lean) | **covered**. Finite frame/noise sums and resulting aligned covariance coefficients. |

The [machine-readable ledger](lean/docs/SUPPLEMENT_CORRESPONDENCE.json) lists the declarations and scope. `SupplementAudit.lean` checks 138 supplementary entries, some overlapping the 498 main entries, and audits the transitive axioms of **all** retained mathematical declarations. A fresh source build and a standard-only axiom audit establish validity of the Lean statements, not automatic equivalence to a more general LaTeX statement.

The official [20 October verification report](lean/verification/20261020/README.md) gives the actual module count, source hashes, statement comparison and kernel replay list. The repository remains private; public GitHub or Zenodo release requires explicit author approval.
