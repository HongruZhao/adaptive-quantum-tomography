# Release contents and licenses

The GitHub repository distributes the main paper, Lean proof sources, verification reports and Python simulation materials. The versioned [Zenodo software record](https://doi.org/10.5281/zenodo.23523803) contains the Lean project and its proof documentation only.

The software retains the MIT licenses in `lean/LICENSE` and `simulation/LICENSE`. The manuscript remains subject to its authors' rights and is not assigned the software license. Upstream dependencies retain their respective licenses.

The verification scope is described in [MAIN_RESULTS.md](MAIN_RESULTS.md), [SUPPLEMENT_RESULTS.md](SUPPLEMENT_RESULTS.md) and [LEAN_FORMALIZATION.md](LEAN_FORMALIZATION.md). Compilation and proof checking do not mechanically verify the Python simulations or establish literature priority.
